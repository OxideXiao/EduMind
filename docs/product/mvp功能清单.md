## MVP 功能清单（1.5 周可交付版）

### 前排功能 — 演示时用户直接可见

| # | 功能 | 优先级 |
|---|------|--------|
| F01 | 登录注册 + 角色切换（教师 / 学生） | P0 |
| F02 | 课程创建 + 邀请码加入 | P0 |
| F03 | 知识图谱可视化 — **学生视图**（个人掌握度颜色 + 推荐路径） | P0 |
| F04 | 知识图谱可视化 — **教师视图**（全班平均 + 薄弱点高亮 + 下钻） | P0 |
| F05 | 学情看板（完成率、活跃度、风险人数） | P0 |
| F06 | 测验作答 + 自动评分（单选 + 判断） | P0 |
| F07 | 智能提醒通知列表（站内通知 + 铃铛红点） | P0 |

### 后排功能 — 逻辑在背后，演示时能跑通

| # | 功能 | 优先级 |
|---|------|--------|
| F08 | **Heartbeat 每日定时任务**（22:00 扫描学情 → 生成提醒 → 更新记忆） | P0 |
| F09 | **学生个人记忆**（`student_memory` 字段，LLM 每日自动维护） | P0 |
| F10 | 学习计划生成（点击触发，LLM + prompt 记忆拼接） | P1 |
| F11 | 教学建议生成（教师端点击触发，LLM 输出） | P1 |
| F12 | 预填充演示数据（1-2 门课完整数据，保障 Demo 流畅） | P0 |

### 已砍功能

| 砍掉 | 原因 |
|------|------|
| AI 半自动导入课程大纲 | 用预置数据替代 |
| 教学周报定时推送 | 看板已覆盖同等信息 |
| 一键创建专项练习 | 非核心路径 |
| 独立 Memory 向量数据库 | prompt 拼接已足够 |
| Agent 事件驱动协同架构 | 统一串行编排替代 |
| 4 个独立 Agent 服务 | 统一 LLM 编排服务替代 |
