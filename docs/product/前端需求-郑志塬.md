## 1. 文档目的

本文档明确前端负责人 **郑志塬** 在本阶段的需求范围、功能清单、验收标准、对接关系与交付物，作为开发、联调与验收依据。

前端职责边界：

- **负责**：教师端 / 学生端页面、交互入口、表单与结果展示、前端联调对接。
- **不负责**：后端接口实现、数据库设计、AI Agent 能力实现、服务器部署（分别由冯宇康、卢克斌、徐斌负责）。

## 2. 背景与目标

### 2.1 背景

当前平台已具备登录、课程、知识图谱、测验、学情看板、学习计划 / 教学建议、通知等 MVP 能力。为支撑 JavaEE 课程真实开课，需补齐教师配置入口与学生作业 / 学习相关页面，并完善 AI 结果展示。

### 2.2 本阶段前端目标

1. 教师端可完成：导入学生、导入知识点、管理教学资源、管理题库、发布作业。
2. 学生端可完成：查看 / 提交作业，顺畅使用学习计划与通知提醒。
3. AI 相关结果（学习计划、教学建议、出题结果等）在页面上可完整展示。
4. 配合测试反馈，修复前端页面、按钮、表单、展示类问题。

## 5. 页面与入口规划

### 5.1 教师端需新增 / 补齐的入口

建议挂在课程上下文（进入某门课后）或课程卡片操作区，入口文案需对教师可见、可理解：

| 入口 | 建议位置 | 对应页面 / 交互 |
|------|----------|-----------------|
| 导入学生 | 课程成员 / 课程管理 | 上传名单 → 结果反馈 |
| 导入知识点 | 知识图谱页或课程管理 | 上传 → 刷新图谱 |
| 教学资源 | 课程侧栏或图谱节点侧栏 | 资源管理页 |
| 题库管理 | 课程侧栏 | 题库列表 + 导入 / 编辑 |
| 发布作业 | 课程侧栏或题库页 | 作业发布表单 |

侧栏 / 面包屑需使用**页面中文名**（如「题库管理」「作业发布」），禁止直接展示路由片段。

### 5.2 学生端需新增 / 补齐的入口

| 入口 | 建议位置 | 对应页面 / 交互 |
|------|----------|-----------------|
| 我的作业 | 课程侧栏或学习页 | 作业列表 → 详情 → 提交 |
| 学习计划 | 已有，需完善展示 | 生成、内容、进度 |
| 通知中心 | 已有，需完善 | 列表、红点、已读 |

### 5.3 建议路由（与后端联调后可微调）

| 路径 | 页面名 | 角色 |
|------|--------|------|
| `/courses/:courseId/members` 或弹层 | 课程成员 / 导入学生 | 教师 |
| `/courses/:courseId/resources` | 教学资源 | 教师 |
| `/courses/:courseId/question-bank` | 题库管理 | 教师 |
| `/courses/:courseId/assignments` | 作业管理（教师发布） | 教师 |
| `/courses/:courseId/assignments` 或 `/homework` | 我的作业（学生） | 学生 |
| `/courses/:courseId/assignments/:id` | 作业详情 / 提交 | 学生 |
| （可选）`/change-password` | 修改密码 | 学生首次登录 |

## 6. 交互与展示要求

### 6.1 通用

1. 所有关键操作需有加载态、成功提示、失败提示（含后端错误信息展示）。
2. 导入类功能需展示：文件选择、模板下载（若后端提供）、导入进度 / 结果摘要。
3. 空态、无权限、接口失败需可理解，避免白屏。
4. 角色隔离：教师入口对学生不可见，反之亦然。
5. 与现有设计系统一致（钢蓝 accent、现有侧栏 / 卡片风格），新增页不另起一套视觉。

### 6.2 导入学生（FE-01）

- 支持选择文件上传（格式以后端约定为准，如 CSV / Excel）。
- 展示导入成功人数、失败行及原因。
- 导入成功后成员列表可刷新。

### 6.3 题库 / 作业（FE-04、FE-05、FE-06）

- 题库：列表字段至少含题干摘要、题型、关联知识点。
- 作业发布：标题、说明、截止时间、题目选择或数量、提交方式（含文件类说明）。
- 学生提交：未提交 / 已提交状态清晰；文件提交需有选择文件与确认提交。

### 6.4 AI 展示（FE-07、FE-10～FE-12）

- 生成按钮防重复点击；超时与失败可重试。
- 结构化展示（列表、优先级、摘要），避免只甩原始 JSON。
- 学习计划页补充「生成依据」说明文案（与卢克斌文档对齐）。

## 7. 非功能需求

| 类别 | 要求 |
|------|------|
| 兼容 | 现代 Chrome / Edge 最新两个版本 |
| 性能 | 常规列表页首屏可交互；导入结果列表过长时需可滚动 |
| 安全 | Token 鉴权沿用现有方案；不在前端写死密钥 |
| 联调 | 仅请求 Spring `:8080`；不直连 Agent（AI 经后端代理，与现架构一致） |
| 可测 | 关键路径可被测试组按模板记录复现 |

## 8. 验收标准

### 8.1 功能验收（对照第一优先级）

- [ ] 教师可在课程中找到并完成「导入学生」全流程（含结果反馈）。
- [ ] 教师可完成「导入知识点」并在图谱 / 列表看到更新。
- [ ] 教师可进入教学资源管理并完成关联知识点的基本操作。
- [ ] 教师可进入题库管理页，完成查看 / 新增或导入入口操作。
- [ ] 教师可发布作业（至少一种非纯选择题或文件说明类，以后端为准）。
- [ ] 学生可查看作业并完成提交（含状态反馈）。
- [ ] 学生学习计划、通知提醒展示完整可用。
- [ ] 教师学情看板 / 掌握度相关页面无阻塞性前端缺陷。

### 8.2 质量验收

- [ ] 黄靖惠、吕熙悦、清风徐来反馈的高优先级前端问题已关闭或有明确排期。
- [ ] 主要新页面有中文面包屑 / 侧栏名称。
- [ ] 联调环境可演示：导入 → 配置内容 → 学生作业 → 学情查看。
